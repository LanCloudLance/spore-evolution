# 孢子离线试玩版 · Mac + Windows

完整游戏可离线运行，包含最新配乐与双手操作键位。下载与你电脑对应的 ZIP，完整解压后启动。

| 平台 | 文件 | 启动 |
| --- | --- | --- |
| Windows 10 / 11，Intel / AMD 64 位 | `spore-offline-windows.zip` | `启动孢子.exe` |
| macOS 12+，Apple 芯片 / Intel | `spore-offline-mac.zip` | `启动孢子.command` |

无需联网或安装 Node / Python；请保留启动窗口。浏览器打开 `http://127.0.0.1:49325/`，使用同一浏览器用户可以继续存档。包中不包含玩家存档，换电脑或浏览器不会自动迁移。

本版包含微生物、海洋、潮间带、陆地、早期族群以及祖先分支。左手 WASD，右手 J/K/L/U/I/O；配乐默认静音，可开启并分别调节音乐与音效。

公开源码构建及回归检查见 Actions。离线包已经过包校验、断网操作和存档回读；Windows 原生启动检查会在 GitHub Windows 环境执行。玩家电脑的默认浏览器调用与主观试玩仍待验证，本次以预发布试玩版交付。

`SHA256SUMS.txt` 提供两个 ZIP 的校验值。两种离线包均包含第三方许可说明。
